# 🏥 Hospital Enquiry Management System

A multilingual Hospital Enquiry Management System designed to simplify patient enquiry handling and improve communication between patients and hospital front desk staff.

This project was built as a functional prototype for the TalentLync Full Stack Intern Home Exercise.

## 🌟 Features

### 👨‍⚕️ Patient Module
- Raise new enquiries
- Book appointment enquiries
- Department enquiry
- Billing enquiry
- Other enquiry types
- Track enquiry status using phone number
- Token generation after successful submission
- Voice assistance for accessibility
- Multilingual interface

### 👩‍💼 Front Desk Staff Module
- View enquiry queue
- Filter enquiries
- Assign enquiries to staff
- Mark enquiries as In Progress
- Mark enquiries as Resolved
- Add resolution notes
- Dashboard showing enquiry statistics

## 🌐 Multilingual Support

Designed for hospitals where many patients cannot read English fluently.

Supported Languages:
- 🇬🇧 English
- 🇮🇳 Hindi
- 🇮🇳 Telugu

The application also provides speech support to improve accessibility.

## 🎯 Problem Statement

Design a Hospital Enquiry Management Software for a hospital where **60% of patients do not read English fluently.**

### Solution

This prototype addresses the problem by providing:

- Language selection
- Voice guidance
- Large icon-based interface
- Simple enquiry workflow
- Token-based enquiry tracking
- Staff management dashboard

## 🛠️ Technologies Used
